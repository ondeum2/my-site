# 사이트 설계도(PRD) — 발주서 도우미 (가칭)

작성일: 2026-10-17 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
거래 업체에 보낼 **비품·장비 주문서**와 **A/S 요청서**를 빠르게 만들고, 문서(인쇄·PDF) 또는 카톡·문자용 글로 골라서 보내고, 기록을 모아 보는 나 혼자 쓰는 업무용 사이트.

## 2. 사용자
- 누가: 나 혼자 (사장님·담당자 1명). 손님이 들어오는 사이트가 아니라 **내부 업무용**이다.
- 받는 쪽: 거래 업체 (비품·장비 공급 업체, A/S 업체)
  - 문서로 받기를 원하는 업체 → 인쇄·PDF
  - 카톡·문자로 받기를 원하는 업체 → 글 복사

## 3. 쓸 때 가장 중요한 것
1. 빨리 쓸 수 있을 것 — 우리 정보와 거래처는 저장해 두고 골라서 자동으로 채운다
2. 업체가 원하는 방식으로 보낼 것 — 같은 발주서를 **문서형 / 문자형** 두 가지로 바로 볼 수 있다
3. 나중에 찾을 수 있을 것 — 언제 무엇을 어느 업체에 발주했는지 목록으로 본다

## 4. 믿게 할 증거
- 해당 없음 (내부 업무용). 발주서 자체가 깔끔하고 정확하게 보이는 것이 신뢰다.

## 5. 핵심 버튼
- 버튼 이름: **발주서 만들기**
- 누르면: 주문 / A/S 중 고르고 → 거래처 고르고 → 내용 입력 → 미리보기
- 미리보기 화면 버튼: **인쇄·PDF 저장** · **카톡·문자용 복사** · **저장(기록에 남기기)**

## 6. 페이지 구성
1. **잠금 화면** — 비밀번호 입력 (나만 들어오게)
2. **발주 목록(첫 화면)** — 최근 발주서 목록 + "발주서 만들기" 버튼, 상태 표시와 업체·종류로 찾기
3. **발주서 작성** — 종류(비품·장비 주문 / A/S 요청) 선택 → 입력 → 미리보기(문서형 / 문자형 탭)
4. **거래처 관리** — 업체 이름·연락처 저장, 고치기, 지우기
5. **설정** — 우리 쪽 정보(회사명·담당자·연락처·기본 배송지) 한 번 저장

## 7. 발주서에 들어갈 항목
공통
- 발주일 (작성하는 날짜로 자동 지정, 필요하면 고칠 수 있음)
- 받는 업체 (거래처 목록에서 선택)
- 담당자, 연락처, 배송지 (설정에 저장한 값으로 자동 채움, 그때그때 고칠 수 있음)

비품·장비 주문
- 품목, 규격, 수량 (여러 줄 추가 가능)

A/S 요청
- 장비명, 고장 내용

※ 가격(단가·합계)은 사용자가 고르지 않아 넣지 않는다.

## 8. 정확해야 하는 사실
- 우리 회사명: (미정 — 설정 화면에서 입력)
- 담당자: (미정 — 설정 화면에서 입력)
- 연락처: (미정 — 설정 화면에서 입력)
- 기본 배송지: (미정 — 설정 화면에서 입력)
- 거래처 정보: (미정 — 거래처 관리에서 입력)

## 9. 이번에 넣지 않을 것
- 단가·합계 등 가격 계산
- 업체에 이메일·카톡 자동 발송 (이번엔 인쇄·PDF와 복사까지만)
- 업체가 링크로 들어와서 확인하는 기능
- 여러 직원·지점 계정, 회원가입
- 사진 올리기 (고장 사진 등)

## 10. 첫 화면 한 문장 후보
1. 주문서와 A/S 요청서, 1분 만에 만들어 보내세요.
2. 거래처를 고르면 발주서가 절반은 채워져 있어요.
3. 문서로도, 카톡으로도 — 업체가 원하는 방식으로.

## 11. 다음에 할 것
- 단가·합계 칸 (필요해지면)
- 고장 사진 첨부
- 이메일 자동 발송
- 자주 쓰는 품목 저장해서 골라 쓰기
- 발주 기록 엑셀(CSV) 내려받기

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 깔끔한 (하얀 바탕, 표가 잘 보이는 단정한 화면) · 참고 디자인: 없음 — 클로드가 정함
- 데이터 저장: 예 → Supabase(leaderpl-admin 스킬 기준) — 발주서, 거래처, 우리 쪽 정보 저장
- 잠금: 사이트 전체를 관리자 비밀번호(ADMIN_PASSWORD)로 잠금
- 발주 상태: 발주함 → 납품·처리 완료
- 문서형: 인쇄에 맞는 A4 한 장 모양, 브라우저 인쇄 기능으로 인쇄·PDF 저장
- 문자형: 줄바꿈이 정리된 글, "복사" 버튼 한 번으로 복사
- 회원가입: 이번엔 아니요
- 배포: 기존 my-site 저장소·Vercel 안의 /balju 주소에 추가 (Supabase·관리자 비밀번호를 같이 씀, 표 이름은 po_ 로 시작해 기존 표와 섞이지 않음)

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 깔끔한 분위기로 정하고 발주서 작성 → 미리보기(문서형·문자형)부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. Supabase 저장 → 비밀번호 잠금 → 발주 목록·거래처 관리·설정 화면까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
