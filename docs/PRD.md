# 사이트 설계도(PRD) — 비품·장비 요청 접수 사이트

작성일: 2026-10-17 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
회사 직원이 소모품·비품·장비 구입과 A/S를 한 곳에서 신청하고, 관리자가 접수·도착을 체크해 진행 상황을 알려 주는 사내 요청 사이트.

## 2. 손님 (요청하는 사람)
- 누가: 회사 직원
- 어디서 알고 오나: (미정) — 사내 공지·메신저로 주소를 알릴 예정이면 적어 둔다

## 3. 직원이 궁금한 것 (요청하기 전에)
1. 무엇을 적어야 하는지 (품목·수량·A/S 증상 등)
2. 누가 승인하는지
3. 내 요청이 어디까지 진행됐는지, 얼마나 걸리는지

## 4. 믿게 할 증거 (실제로 있는 것만)
- 승인 기준을 사이트에 분명히 적는다: 20만 원 이상은 대표 승인
- 진행 상황(접수·도착)이 체크되어 보인다는 것 자체가 믿음의 근거
- 후기: 해당 없음 (사내 사이트)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 요청하기
- 누르면: 요청 폼

## 6. 페이지 구성 (위에서 아래로)
1. 첫 화면 — 한 문장 + [요청하기] 버튼
2. 이렇게 진행돼요 — 요청 → 접수 → (20만 원 이상은 대표 승인) → 도착
3. 요청 종류 안내 — 소모품 / 비품 / 장비 구입 / A/S, 각각 무엇을 적으면 되는지
4. 요청 폼
5. 요청 현황판 — 접수번호 없이 목록에서 내 요청을 찾는다
   - 최근 요청이 표로 보인다: 요청일 · 부서 · 이름(가운데 글자 가림, 예: 김*수) · 품목 · 접수 ✔ · 도착 ✔
   - 부서를 고르면 우리 부서 요청만 보인다
   - 연락처·금액·A/S 증상은 현황판에 보이지 않는다 (관리자만 봄)
   - 요청을 보낸 직후 "현황판에서 확인하세요" 안내와 바로가기 버튼
- 관리자 페이지(/admin) — 요청 목록, 각 요청에 **접수 / 도착 체크 칸**

## 7. 요청 폼에서 받을 것
- 이름, 부서, 연락처(사내 메신저 또는 내선)
- 요청 종류: 소모품 / 비품 / 장비 구입 / A/S
- 품목명, 수량, 예상 금액(대략) — 20만 원 이상이면 "대표 승인이 필요해요" 안내
- A/S일 때: 고장 증상
- 필요한 날짜 (선택)
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 승인 기준: 20만 원 이상은 대표 승인 (20만 원 미만 처리자: (미정))
- 처리 기간: (미정)
- 담당자: (미정)
- 연락 방법: (미정)

## 9. 이번에 넣지 않을 것
- 회원가입·로그인
- 대표 승인을 사이트 안에서 누르는 기능 (이번엔 관리자가 체크)
- 결제, 사진 올리기, 알림 메일

## 10. 첫 화면 한 문장 후보
1. 필요한 비품, 여기 한 곳에서 요청하세요.
2. 소모품부터 장비 A/S까지, 요청하고 진행 상황을 바로 확인하세요.
3. 적고, 보내고, 도착까지 확인하는 사내 비품 요청함.

## 11. 다음에 할 것
- 처리 기간·담당자·연락 방법 채우기 (사이트 열기 전)
- 20만 원 미만은 누가 처리하는지 정하기
- 대표 승인 버튼, 처리 완료 알림, 고장 사진 첨부 (원하면)

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 고급스러운 · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin (요청 목록, 접수 / 도착 체크 칸)
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 요청 폼 → Supabase 저장 → /admin 관리자 페이지(접수 / 도착 체크)까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
